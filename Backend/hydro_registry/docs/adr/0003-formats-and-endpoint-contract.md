# ADR-0003 — Форматы, шапка, контракт endpoint'а и LLM-клиент

**Статус:** принято · 2026-06-25

## Форматы
- **Excel** (`.xls`/`.xlsx`) — многолистовой, многоуровневая шапка. Основной кейс.
- **CSV** — один плоский лист, без межлистовой склейки.
- **SQL** — **не реализуется** (исключено из скоупа).

## Парсинг шапки (гибрид)
Код детерминированно флэттит многоуровневую шапку и **протягивает** значения
объединённых ячеек (merge fill), формируя флэт-имена колонок. LLM получает флэт-имена
**вместе с 1–3 сэмплами данных** под каждой колонкой — это резко повышает точность
маппинга на грязных госфайлах.

## Определение типа сооружения
`facility_type` извлекает **тот же LLM-вызов**, что строит карту маппинга — по
строке-заголовку («…всех каналов…») и набору колонок (выбор 10a=a).

## Контракт endpoint'а
- **Синхронный** (10a=a): клиент ждёт, в ответ — полный отчёт. Допустимо для хакатона
  (нет Celery/воркера в проекте).
- **Доступ:** открытый, без аутентификации (10b=c) — хакатон, не прод.
- **Тело ответа (отчёт об импорте):**
  ```json
  {
    "created": 142,
    "skipped_duplicates": 38,
    "conflicts": [
      {"key": "...", "field": "efficiency_fact", "existing": 0.73,
       "incoming": 0.70, "sheet": "Корректировка"}
    ],
    "warnings": ["..."],
    "unmapped_columns": ["..."]
  }
  ```

## LLM-клиент
Используется пакет **`openrouter`** (`from openrouter import OpenRouter`) строго по спеке
(10c=b), модель `openrouter/auto`, ключ `OPENROUTER_API_KEY` из `.env`.

> **Риск/fallback:** пакет `openrouter` малоизвестен; при нестабильности или отсутствии в
> PyPI — переключиться на OpenAI-совместимый клиент (`openai` SDK,
> `base_url="https://openrouter.ai/api/v1"`, тот же ключ и модель). Адаптер LLM изолирован
> в `infrastructure/llm/`, поэтому замена не затрагивает доменную логику.

## Промпт LLM (требования)
- Содержит каталог целевых полей с русскими описаниями и типами.
- Явно запрещает выдумывать значения; неизвестные колонки → не маппить (уходят в
  `unmapped_columns`); отсутствующие данные → оставлять пустыми.
- Возвращает строго структурированный JSON: `{facility_type, mapping: {col_index: field}}`.
