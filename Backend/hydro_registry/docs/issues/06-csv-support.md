# [ingestion] Поддержка формата CSV

> **Триаж:** `ready-for-agent`
> **Источник:** [PRD](../prd/file-import-endpoint.md)
> (ADR [0003](../adr/0003-formats-and-endpoint-contract.md))

## What to build

Приём CSV-файлов тем же endpoint'ом. CSV трактуется как **один плоский лист** без
листовой структуры и без межлистовой склейки. Дальше используется тот же конвейер:
определение блока шапки/флэт-имён, отброс мусорных строк (если есть), LLM-маппинг,
раскладка, резолвер идентичности и запись. Формат определяется по содержимому/расширению.

## Acceptance criteria

- [ ] `POST /api/import/` принимает `.csv` и формирует отчёт того же вида, что и для Excel.
- [ ] CSV обрабатывается как один плоский лист (без межлистовой логики).
- [ ] Маппинг, дедуп и запись работают так же, как для одного листа Excel.
- [ ] Тест: импорт CSV-фикстуры с каналами создаёт корректные записи и отчёт.
