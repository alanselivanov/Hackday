# [ingestion] Обработка ошибок: неподдерживаемый формат, повреждённый и пустой файл

> **Триаж:** `ready-for-agent`
> **Источник:** [PRD](../prd/file-import-endpoint.md)
> (ADR [0003](../adr/0003-formats-and-endpoint-contract.md))

## What to build

Устойчивость endpoint'а к некорректному вводу. SQL-файл (вне скоупа) → осмысленная
ошибка с понятным сообщением, а не падение. Повреждённый или нечитаемый файл → понятная
ошибка. Пустой файл или файл без распознаваемых строк данных → понятная ошибка/отчёт без
созданных записей. Во всех случаях ответ имеет осмысленный HTTP-статус и тело с причиной.

## Acceptance criteria

- [ ] SQL-файл → осмысленная ошибка (формат не поддерживается), без 500.
- [ ] Повреждённый/нечитаемый файл → понятная ошибка с причиной.
- [ ] Пустой файл / нет строк данных → понятная ошибка или отчёт с `created: 0`, без падения.
- [ ] Ошибочные ответы имеют корректный HTTP-статус и информативное тело.
- [ ] Тесты: загрузка `.sql`, повреждённого и пустого файлов возвращают ожидаемые ошибки.
