# [ingestion] Обработка всех листов и межлистовая склейка

> **Триаж:** `ready-for-agent`
> **Источник:** [PRD](../prd/file-import-endpoint.md)
> (ADR [0002](../adr/0002-multi-sheet-merge-and-identity.md))

## What to build

Расширение импорта на многолистовые Excel-файлы. Обрабатываются **все** листы файла;
каждый лист маппится отдельно (своя шапка → свой LLM-вызов, своя раскладка). Резолвер
идентичности из #03 применяется не только против БД, но и **между листами** в рамках
одной загрузки: одинаковые объекты с разных листов не создают дублей, расхождения между
листами попадают в `conflicts` (с указанием листа-источника).

Проверяется на `датасет(1).xls` с тремя листами (`каналы`, `Лист1`, `Корректировка`).

## Acceptance criteria

- [ ] Все листы Excel-файла обрабатываются, каждый со своей шапкой и маппингом.
- [ ] Объект, встречающийся на нескольких листах, создаётся один раз (`skipped_duplicates` для повторов).
- [ ] Расхождение значений между листами → `conflicts` с указанием листа.
- [ ] Дедуп работает одновременно и между листами, и против существующих записей БД.
- [ ] Тест: импорт многолистовой фикстуры создаёт ожидаемое число уникальных записей; повторы и конфликты отражены в отчёте.
