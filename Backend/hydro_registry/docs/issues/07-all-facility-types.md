# [ingestion] Поддержка всех типов сооружений

> **Триаж:** `ready-for-agent`
> **Источник:** [PRD](../prd/file-import-endpoint.md)
> (ADR [0001](../adr/0001-llm-maps-schema-not-data.md))

## What to build

Расширение импорта за пределы каналов на все типы сооружений: `sluice` (`Sluice`),
`intake` (`WaterIntake`), `pumping` (`PumpingStation`), `dam_dyke` (`DamsAndDykes`),
`post` (`HydroPost`). Каталог целевых полей дополняется специфическими полями каждого
подкласса (общие поля `BaseHydroFacility` уже есть из #01). Репозиторий создаёт базовую
запись и запись нужного подкласса согласно `facility_type`, определённому LLM по
заголовку и набору колонок.

Полные списки полей подклассов — в [file-import-design.md](../file-import-design.md).

## Acceptance criteria

- [ ] Каталог целевых полей покрывает поля всех шести подклассов.
- [ ] Для каждого `facility_type` создаётся корректная пара базовая запись + подкласс.
- [ ] `facility_type` определяется LLM по заголовку/колонкам и драйвит выбор подкласса.
- [ ] Тесты: импорт фикстур для нескольких типов (напр. шлюз и насосная станция) создаёт записи с заполненными специфическими полями.
