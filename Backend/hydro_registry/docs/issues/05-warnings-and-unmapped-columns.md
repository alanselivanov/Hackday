## What to build

Полнота и прозрачность отчёта об импорте. Строка без ключа склейки (нет названия или нет
координат) создаётся как отдельная запись, но сопровождается записью в `warnings`
(«нет ключа для склейки»). Колонки файла, которые LLM не сопоставил ни с одним полем
модели, перечисляются в `unmapped_columns` и игнорируются при записи. Отсутствующие
значения остаются пустыми (LLM не выдумывает данные).

Отчёт расширяется полями `warnings` (список) и `unmapped_columns` (список).

## Acceptance criteria

- [ ] Строка без названия/координат создаётся, но добавляет запись в `warnings`.
- [ ] Колонки без соответствия полю попадают в `unmapped_columns` и не пишутся.
- [ ] Отсутствующие значения остаются пустыми, без подстановки догадок.
- [ ] Отчёт содержит `warnings` и `unmapped_columns`.
- [ ] Тесты: импорт строки без ключа → запись + warning; файл с лишней колонкой → колонка в `unmapped_columns`.
