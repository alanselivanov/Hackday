# Глоссарий — импорт файлов

Единый словарь терминов для фичи «endpoint загрузки файлов». Доменные термины — на
русском (как и весь домен), технические имена полей — на английском (как в моделях).

## Доменные сущности

| Термин | Значение |
|---|---|
| **Сооружение** (facility) | Гидротехнический объект. В БД — строка `BaseHydroFacility` + строка подкласса (multi-table inheritance). |
| **Тип сооружения** (`facility_type`) | Один из: `canal`, `sluice`, `intake`, `pumping`, `dam_dyke`, `post`. Объявляется в строке-заголовке файла («…всех **каналов**…»). |
| **Подкласс** | `Canal`, `Sluice`, `WaterIntake`, `PumpingStation`, `DamsAndDykes`, `HydroPost`. |
| **Водоисточник** (`water_source`) | Источник воды (напр. «р. Иртыш»). Часть ключа идентичности. |
| **Подвешенная площадь** | Орошаемая площадь: регулярная / лиманная / обводнённая (поля `area_*` у `Canal`). |
| **КПД** | Коэффициент полезного действия: проектный (`efficiency_project`) и фактический (`efficiency_fact`). |

## Термины фичи импорта

| Термин | Значение |
|---|---|
| **Сырой лист** (raw sheet) | Один лист Excel / весь CSV как двумерная сетка ячеек до интерпретации. |
| **Блок шапки** (header block) | Верхние строки листа (в примере — строки 3–6) с многоуровневой объединённой шапкой колонок. |
| **Флэт-имя колонки** | Имя колонки, собранное из иерархии шапки через разделитель: `«До реконструкции / Всего протяжённость, км»`. |
| **Протягивание merge** (merge fill) | Заполнение пустых ячеек объединённого диапазона значением «головной» ячейки, чтобы каждый столбец/строка шапки имели значение. |
| **Карта маппинга** (column mapping) | Результат LLM-вызова: соответствие `индекс колонки → поле модели` (+ определённый `facility_type`). Не выдумывает значения — работает с именами колонок и сэмплами. |
| **Сэмпл данных** | 1–3 значения из-под колонки, отправляемые в LLM вместе с флэт-именем для устойчивости маппинга. |
| **Ключ идентичности** (identity key) | `water_source` + `name` + `year_built` + пространственная близость координат (≤ 100 м, PostGIS `ST_DWithin`). Определяет «это тот же объект». |
| **Дубль-совпадение** | Запись с тем же ключом идентичности И совпадающими значениями → в БД не пишем. |
| **Конфликт** (conflict) | Запись с тем же ключом идентичности, но расходящимися значениями → в БД **не пишем**, попадает в отчёт. |
| **Предупреждение** (warning) | Нефатальная проблема: нет ключа склейки, нет координат, и т.п. Импорт продолжается. |
| **Несопоставленная колонка** (unmapped column) | Колонка файла, которую LLM не смог сопоставить ни с одним полем модели. Игнорируется, попадает в отчёт. |
| **Отчёт об импорте** (import report) | JSON-ответ endpoint'а: `created`, `skipped_duplicates`, `conflicts`, `warnings`, `unmapped_columns`. |
